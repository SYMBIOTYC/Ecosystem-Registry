## Scope
Tracks organizations, products, projects, services, websites, tools, technologies, infrastructure, integrations, applications, interfaces, and people/teams. The Tool Registry keeps external catalog candidates separate from the first-party GROUP control-plane tool, its deployed read-only invocations, and source-only approval endpoints.

## Evidence and safety
Repository existence is not equivalent to a working product or deployed service. Public/private visibility is recorded. Private source code, credentials, user data, HAR captures and licensed assets must not be copied into this registry. External catalog data is imported read-only at an immutable revision and carries attribution/license provenance.

## Ownership boundaries
The SpineAnimator SA-Wiki documents the owner-declared operating model that SYMBIOTYC owns the 2Spine / SA product domain for platform and engineering governance. This does not change GitHub repository ownership and is not a legal/IP title determination.

## Snapshot caveat
All numbers are scoped and date-stamped. The two awesome-selfhosted repositories are external partner sources, not SYMBIOTYC-owned assets. Six external self-hosted software records remain catalog candidates. The first-party GROUP control-plane tool has three read-only invocations configured through AMPHETAMIN, but remains deployed_unverified until an authenticated external MCP round-trip passes; its approval endpoints are source-only and not active.
