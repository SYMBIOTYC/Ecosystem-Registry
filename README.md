## Scope
Tracks organizations, products, projects, services, websites, tools, technologies, infrastructure, integrations, applications, interfaces, and people/teams.

## Evidence and safety
Repository existence is not equivalent to a working product or deployed service. Public/private visibility is recorded. Private source code, credentials, user data, HAR captures and licensed assets must not be copied into this registry.

## Ownership boundaries
The SpineAnimator SA-Wiki documents the owner-declared operating model that SYMBIOTYC owns the 2Spine / SA product domain for platform and engineering governance. This does not change GitHub repository ownership and is not a legal/IP title determination.

## Snapshot caveat
This is the first source-backed inventory pass. All numbers are scoped and date-stamped. Unverified product families remain candidates until linked to canonical source repositories, domains, releases or operational checks.
